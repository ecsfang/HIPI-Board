# HIPI 1.7.4

HIPI's devices answer the controller's device ID request (SDI) the way the
HP-IL specification says, and their names no longer begin with `TF`.

## Downloads

| File | What it is |
|------|------------|
| `hipi_7_pico-v1.7.4.uf2` | The firmware for the 7" panel — drag it onto the Pico in BOOTSEL mode |
| `HIPI-SD-card-v1.7.4.zip` | Everything a new SD card needs — unzip it onto the card |
| `hipi_7_pico-v1.7.4.elf` | The firmware with debug symbols, for developers |

## Changed

- **The device ID (SDI answer) follows the HP-IL specification.** It is ASCII
  characters followed by CR LF, at least 7 characters (the HP-41's `FINDID`
  compares 7), and a device that emulates an HP device sends that device's ID:

  | Device | ID before | ID now |
  |--------|-----------|--------|
  | Display (HP 82163) | `TFDISPLAY` | `HP82163A` |
  | Display (HP 92198) | `MC00701A` | `MC00701A` (as before) |
  | Cassette drive | `TFDRIVE` | `HP82161A` |
  | Printer | `TFPRINT` | `HP82162A` |
  | Plotter | `HP7470A` | `HP7470A` (as before) |
  | LEDs | `TFLEDS` | `HIPILED` |
  | Pixels | `TFPIXEL` | `HIPIPIX` |
  | I2C | `TFI2C` | `HIPII2C` |
  | Terminal | `TFTERM` | `HIPITRM` |

  `FINDID` on the HP-41 now finds the drive with `"HP82161A"` (or `"HP82161"`:
  only the first 7 characters are compared), as it does a real one.
- **The devices' names** (device list, loop map, Devices menu, `CONFIG.TXT`)
  are now `DISPLAY`, `DRIVE`, `PRINTER`, `PLOTTER`, `LEDS`, `PIXEL`,
  `TERMINAL` and `I2C`; they began with `TF` (`TFDRIVE`...). The name is a
  label; the ID is what a program on the HP-41 looks for.
- The device list shows `HP82163A` for the display model, as the ID says.

## Upgrading

- Flash `hipi_7_pico-v1.7.4.uf2` as usual. An older `CONFIG.TXT` is read with
  the old names (`media.TFDRIVE=...`, `disabled_devices`, `device_order`) taken
  as the new ones, and saved with the new names. Nothing needs editing.
- **Programs that look for a device with `FINDID`** need the new ID:
  `"TFDRIVE"` becomes `"HP82161A"`, `"TFI2C"` becomes `"HIPII2C"` (the table
  above has the rest). The device's address on the loop is not affected.
- `SETCLK` for the HP-71 (`prgms/`) only mentions `TFI2C` in a comment; it
  works as before.
- Pictures in the manual may still show the old names.
