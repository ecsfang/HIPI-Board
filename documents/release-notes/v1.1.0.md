# HIPI 1.1.0

This release brings **hipiview**: HIPI's 7" screen on your PC, live, to watch,
record and even operate HIPI from the computer. There's also a ready-made SD
card package, effects for the colour pixels, and a number of smaller
improvements and fixes.

## Downloads

| File | What it is |
|------|------------|
| `hipi_7_pico-v1.1.0.uf2` | The firmware for the 7" panel — drag it onto the Pico in BOOTSEL mode |
| `HIPI-SD-card-v1.1.0.zip` | Everything a new SD card needs — unzip it onto the card |
| `hipiview-windows-v1.1.0.zip` | hipiview for Windows 10/11 — a single `hipiview.exe`, nothing to install |
| `hipiview-linux-x64-v1.1.0.tar.gz` | hipiview for Linux (needs SDL2: `sudo apt install libsdl2-2.0-0`) |
| `hipi_7_pico-v1.1.0.elf` | The firmware with debug symbols, for developers |

## New

### hipiview — HIPI's screen on the PC (7" panel)

- **See HIPI's screen in a window on the PC**, exactly as on the panel: text,
  plots, the Tape view, menus, the screen saver. It works through a fourth USB
  serial port, *HIPI Display Mirror*, and is found automatically.
- **Record videos** straight to a file (**R**), take screenshots (**S**), or
  save the stream and turn it into a video afterwards (`--log`, `--replay`,
  `--render`) — no camera, no reflections.
- **Use HIPI from the PC**: with *Mirror to PC < Control >*, a mouse click is a
  tap on the screen, dragging is a swipe, and the keyboard works the buttons
  (Enter = OK, arrows = ▲/▼ and the views, Backspace = X, Tab = Shift).
- **Touch rings** show where was clicked — in the window and in the video.
- **Runs on Linux and Windows.**
- New setting **Settings → Screen → Mirror to PC < Off / View / Control >**
  (off by default). With hipiview closed, the mirror costs nothing; HIPI
  only sends while hipiview is connected and has asked for the screen.
- Reliable over USB: lost packets are sent again, the Tape view's pictures
  are sent only once and kept in a cache on the PC, and hipiview picks up
  again by itself when HIPI restarts, is unplugged, or goes into Bootsel mode.

See `tools/hipiview/README.md`.

### SD card package

- `HIPI-SD-card.zip` holds everything a new SD card needs: the Tape view's
  pictures, an example cassette and a short README. Format the card, unzip,
  done. It's in the project folder and with every release.

### Colour pixels (`TFPIXEL`)

- **`N`** tells HIPI how many pixels are connected (`0N10`); it's remembered.
- **Effects** that run by themselves: comet (`EC`), colour bands (`EM`),
  stars (`ES`), bouncing balls (`EB`), fire (`EF`), fade out (`EO`) and a
  rainbow (`ER`) — on all pixels or a range, up to four at once, with
  settings for colours, speed and more. `E` alone stops them.
- **Current limit:** HIPI turns the brightness down by itself when many
  pixels would be bright at once, to stay within what USB can deliver.

### More

- **Plotter paper:** white (dark pens) or black (light pens) — in the
  Plotter menu and Settings → Screen.
- **Choose the view from the HP-41** with `ESC # V` followed by a device's
  HP-IL address.
- **HP-IL signals view:** how the bits are marked — bands, lines or nothing
  (*Bit cells* in its menu).
- **The screen saver** (clock, HP-IL rain, goose) now gets the whole screen;
  an open menu or the button strip comes back when it ends.

## Fixed

- Plotter: changing the paper colour left the area under the button strip in
  the old colour, and lines drawn there while the strip was showing were
  missing.

## Documentation

- The project README has been rewritten.
- `pcb/README.md` describes how to connect the HP-IL cables — by the pin in
  the plug, not the marking on the cable.
- The User Manual and the Guide cover all of the above.

## Upgrading

- Flash `hipi_7_pico-v1.1.0.uf2` as usual. Your `CONFIG.TXT` keeps working;
  new settings get their defaults.
- The SD card doesn't need to change. The new package is for new cards.
