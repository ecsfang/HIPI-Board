# HIPI 1.4.0

The display's output can now be saved as plain text, the plotter has a
wide pen, and cassettes can be `.lif` files too. Plus a few fixes in the
plotter view and the menus.

## Downloads

| File | What it is |
|------|------------|
| `hipi_7_pico-v1.4.0.uf2` | The firmware for the 7" panel — drag it onto the Pico in BOOTSEL mode |
| `HIPI-SD-card-v1.4.0.zip` | Everything a new SD card needs — unzip it onto the card |
| `hipi_7_pico-v1.4.0.elf` | The firmware with debug symbols, for developers |

## New

- **Save the display as text:** everything the display has shown since
  start-up is kept as plain text — program listings, `CAT`, whatever a
  program wrote, also what has long scrolled off the screen (up to 1 MB).
  In the Display view: OK → **Text > Save as text (n lines)** saves it as
  `text/display_<n>.txt` on the SD card. **Start anew** forgets what's kept,
  like a record button. A program can save it too: `ESC # T`.
  - Works for both displays (HP 82163 and HP 92198).
  - Escape sequences and control codes are left out, one line per line;
    the 92198's Roman-8 characters (Å, Ä, Ö …) are saved as UTF-8.
- **Plotter pen:** **Pen < Thin / Wide >** in the Plotter view's menu, like
  putting a pen with a broader tip in the plotter. Only what's drawn after
  the change gets it, so thin and wide lines can be mixed in one plot.
  HIPI always starts with Thin.
- **`.lif` cassettes:** the file picker lists `.lif` files as well as
  `.dat` files (both are LIF images). Create media still makes `.DAT`.

## Fixed

- **Plot view Fit** kept the previous plot's scale after `IN` or **Clear
  plotter**, so a new, smaller plot was drawn small. It now fits each new
  plot afresh.
- **The display's cursor** jumped into a message box (e.g. after a
  screendump) and stayed there, beside the menu. It goes back where it was
  — also after the demo's captions and when a menu is closed by touch.
- **Menu corners:** the small corners outside a menu's rounded frame now
  follow the view behind it when it changes with the menu open (e.g.
  Paper white → black), and the title band no longer pokes out past the
  rounding.

## Upgrading

- Flash `hipi_7_pico-v1.4.0.uf2` as usual. Your `CONFIG.TXT` keeps working.
- The SD card doesn't need to change; HIPI creates the `text` folder when
  you first save the display's text.
- hipiview: the one from 1.3.1 still works.
