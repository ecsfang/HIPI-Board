# HIPI 1.3.1

A stability release: HIPI could run out of memory and restart (or stop)
after a long time in the demo with hipiview connected. That's fixed. The
Media map now knows HP-71 and HP-75 files, and the demo shows more.

## Downloads

| File | What it is |
|------|------------|
| `hipi_7_pico-v1.3.1.uf2` | The firmware for the 7" panel — drag it onto the Pico in BOOTSEL mode |
| `HIPI-SD-card-v1.3.1.zip` | Everything a new SD card needs — unzip it onto the card |
| `hipi_7_pico-v1.3.1.elf` | The firmware with debug symbols, for developers |

## New

- **Media map:** every LIF file type of the HP-41, HP-71 and HP-75 is
  known (BASIC, BIN, LEX, FORTH, key, data, text ...). The card on the
  right has two tabs, **BY TYPE** and **BY MACHINE**. **Touch a row** to
  find those files: they keep their colour, the rest turns grey. A touched
  file shows its type as lifutils names it (`BAS71 (SP)`), its code, and a
  padlock for a secure or private file.
- **Cassette contents** (▼ in the file picker) uses the same type names.
- **Demo:**
  - a plot in the **Fit** view, its axes drawn slowly so the view grows
    with them
  - **digitizing** on it
  - **Create media** filled in (nothing is created)
  - the media map of a disk with HP-41, HP-71 and HP-75 files
  - a longer analyzer session on a loop with PILBOX's PC devices and three
    devices after HIPI, so the **loop map** has more to show, with a
    device's details box
  - the **Hardware test** page
  - a longer printout
- **Crash report:** if HIPI ever crashes, it restarts by itself and the
  USB log then says what happened and where.

## Fixed

- After a long time in the demo with hipiview connected, HIPI ran out of
  memory and restarted or locked up. It now uses far less of its own RAM:
  the button strip and the screen saver's geese are drawn from the
  display's memory instead.
- hipiview could wait for ever (no picture, no message) when HIPI had
  ended a session that was busy from its start. **Use the hipiview of this
  release.**
- Loop map: the device ID of a device after HIPI was sometimes not kept,
  or shown on another card.
- In `tools/hipiview`, a plain `make` builds hipiview again.

## Changed

- Only the 7" panel (LT7683) is supported. The 5" panel (RA8875) is no
  longer built.

## Upgrading

- Flash `hipi_7_pico-v1.3.1.uf2` as usual. Your `CONFIG.TXT` keeps working.
- The SD card doesn't need to change.
- If you use hipiview: build it again from this version (`make` in
  `tools/hipiview`).
