# HIPI 1.7.0

A shortcut on the screen's left edge takes you straight to the loop map (or
the view you choose), HIPI starts with the view of the first device that is
switched on, and HIPI no longer stands still when a PC program behind
PILBox stops answering.

## Downloads

| File | What it is |
|------|------------|
| `hipi_7_pico-v1.7.0.uf2` | The firmware for the 7" panel — drag it onto the Pico in BOOTSEL mode |
| `HIPI-SD-card-v1.7.0.zip` | Everything a new SD card needs — unzip it onto the card |
| `hipi_7_pico-v1.7.0.elf` | The firmware with debug symbols, for developers |

## New

- **A shortcut on the left edge.** A touch in the middle of the screen's left
  edge opens the **Loop map** — or the view chosen in **Settings → Shortcut**
  (Analyzer, HP-IL signals, Characters, Hardware test, or Off).
  Touch it again to go back. Like the info box (top-left corner) and the
  device list (bottom-left).

## Fixed

- **HIPI stood still when the PC didn't answer through PILBox.** With pyILPER
  in `COFF`/`COFI`, HIPI waited for its answer to each frame with no time
  limit. If pyILPER stopped, hung or lost a byte, or the port closed at the
  wrong moment, HIPI stood still: no screen, no touch, no hipiview, and only
  a restart helped. HIPI now keeps running while it waits.
  - After **2 s** with no answer it drops the frame (the HP-41 shows
    `TRANSMIT ERR`), switches PILBox to `TDIS` and shows a warning.
  - The HP-41's next try works without the PC's devices.
  - When pyILPER starts again, everything carries on as usual.

## Changed

- **The first view after start-up** is now that of the first device on
  the loop (in loop order) that is switched on and has a view. Before, it was
  always the Display view, even with `TFDISPLAY` switched off. With no such
  device, HIPI starts with the **Loop map**. The same rule applies when HIPI
  can't go back to a view whose device has since been switched off.
- `CONFIG.TXT`: new `shortcut=loopmap|analyzer|signals|chartable|hwtest|off`
  (the left edge's shortcut; `loopmap` if it's missing).

## Upgrading

- Flash `hipi_7_pico-v1.7.0.uf2` as usual. Your `CONFIG.TXT` keeps working.
- The SD card doesn't need to change.
- **hipiview:** 1.6.0 works as it is; 1.7.0 is the same.
- Going back to 1.6.0: it ignores `shortcut=`.
